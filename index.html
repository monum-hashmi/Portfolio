01 — Research

Does the result mean what it claims?

That question runs through everything. Full manuscripts and code live at github.com/monum-hashmi/research-papers.

Featured First author Manuscript under supervisor review

Validity-Aware Evaluation of EEG–ECG Affective-State Fusion

A negative-control framework that asks whether the gains attributed to EEG–ECG fusion survive when the pairing between the two signals is deliberately broken.

They don’t. Correct pairing scored below a label-matched control — Pair-Validity Index −0.012 (valence), −0.008 (arousal) — so the reported “fusion benefit” is an artifact of evaluation design, not physiological correspondence. The null result is the finding.

First of three authors Under review

MSAFE-GC: Compression-Robust, Explainable Deepfake Detection

A multi-scale architecture fusing fine, medium, and coarse resolution streams so manipulation artifacts survive the heavy compression real platforms apply — the low-quality tier where single-scale detectors quietly fail. Grad-CAM is used as a diagnostic to confirm the model attends to manipulated regions, not dataset shortcuts.

FaceForensics++ LQ tier · 96.30% acc · 0.9903 AUC

First author Study design · in progress

A Governance Framework for Generative AI in Saudi Higher Education

A three-level governance framework — national, institutional, and classroom — for generative-AI adoption, built from a primary-source review of regulation and university policy. Study design complete; document analysis in progress.

In progress with Daniyal Adeeb

Interpretable Violence Detection: A Transparent Motion-Feature Framework

Replaces black-box video classification with hand-designed motion features and transparent rules, so each prediction decomposes into named physical causes. The emerging finding: feature behaviour is regime-dependent across visual contexts — a failure mode aggregate accuracy hides.

02 — Projects

Systems I’ve shipped

Groundline ↗

A questionnaire-answering pipeline that answers only where a policy clause genuinely supports the answer, and abstains otherwise. Grounding and relevance run as two independent checks, so a grounded-but-irrelevant citation is caught, not trusted.

Multi-Agent Code Review ↗

A LangGraph pipeline routing a pull request through specialised correctness, style, and security agents — each grounded in the surrounding codebase via ChromaDB retrieval, so feedback cites real repository patterns, not just the diff. Served over FastAPI on EC2.

  • LangGraph
  • FastAPI

  • AWS EC2
  • OpenRouter

Application-Layer Intrusion Detection ↗

A fine-tuned BERT classifier separating prompt-injection, SQL-injection, and PII-leakage attempts from benign lookalikes at the application layer of LLM systems. I owned adversarial dataset curation, the labelling schema, and model training.
