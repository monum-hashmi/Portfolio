Research

The through-line: I care whether a measured result means what it claims. Full manuscripts and code — github.com/monum-hashmi/research-papers.

  1. First author · manuscript under supervisor review

    Validity-Aware Evaluation of EEG–ECG Affective-State Fusion

    A negative-control framework that asks whether the gains attributed to EEG–ECG fusion survive when the pairing between the two signals is deliberately broken. They don't — correct pairing scored below a label-matched control (Pair-Validity Index −0.012 for valence, −0.008 for arousal), so the reported “fusion benefit” is an artifact of evaluation design, not physiological correspondence.

  2. First of three authors · under review

    MSAFE-GC: Compression-Robust, Explainable Deepfake Detection

    A multi-scale architecture that fuses fine-, medium-, and coarse-resolution streams so manipulation artifacts survive the heavy compression real platforms apply to video — targeting the low-quality tier where single-scale detectors quietly fail. Grad-CAM is used as a diagnostic to confirm the model attends to manipulated regions rather than dataset shortcuts.

    FaceForensics++ low-quality tier · 96.30% accuracy · 0.9903 AUC

  3. First author · study design, analysis in progress

    A Governance Framework for Generative AI in Saudi Higher Education

    A three-level governance framework — national, institutional, and classroom — for generative-AI adoption in Saudi higher education, built from a primary-source review of regulation and university policy. The study design is complete; the document analysis is in progress.

  4. In progress · with Daniyal Adeeb

    Interpretable Violence Detection: A Transparent Motion-Feature Framework

    Replaces black-box video classification with hand-designed motion features and transparent decision rules, so each prediction decomposes into named physical causes instead of a post-hoc saliency map. The emerging finding is that feature behaviour is regime-dependent across visual contexts — a failure mode aggregate accuracy hides.

Projects

  1. Groundline

    A questionnaire-answering pipeline that answers only where a policy clause genuinely supports the answer, and abstains otherwise. It runs grounding and relevance as two independent checks, so a grounded-but-irrelevant citation is caught rather than trusted.

    Python · Nutrient DWS Extraction API

  2. Multi-Agent Code Review System

    A LangGraph pipeline that routes a pull request through specialised correctness, style, and security agents, each grounded in the surrounding codebase via ChromaDB retrieval so feedback cites real repository patterns, not just the diff. Served over FastAPI on EC2.

    LangGraph · FastAPI · ChromaDB · AWS EC2 · OpenRouter

  3. Application-Layer Intrusion Detection for LLM Systems

    A fine-tuned BERT classifier that separates prompt-injection, SQL-injection, and PII-leakage attempts from benign lookalikes at the application layer of LLM systems. I owned the adversarial dataset curation, the labelling schema that keeps attack classes distinct from near-duplicates, and model training.

    HuggingFace Transformers · BERT · PyTorch

  4. Suspicious Vehicle & Person Tracker

    Real-time multi-object tracking with rule-based alerting for stationary person–vehicle pairs inside user-defined regions of interest, calibrated and evaluated against MOT17 ground truth.

    YOLOv8 · DeepSORT · OpenCV
